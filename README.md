# Clinic Appointment System

## Overview

A web application built using ASP.NET Core Razor Pages for managing clinic appointments efficiently.

## Features

* Patient appointment booking
* Doctor schedule management
* Admin dashboard
* Appointment tracking system

## Tech Stack

* C#
* ASP.NET Core
* Razor Pages
* SQL Server

## What I learned

* MVC / Razor Page structure
* Backend logic using C#
* Database integration
* Web application development

## Future Improvements

* Email notifications
* Payment integration
* Mobile-friendly UI
